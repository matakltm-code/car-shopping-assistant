2. MOTIVATION & OBJECTIVE
-------------------------------------------------------------------------------
Car shopping in the Ethiopian local market presents unique regional challenges:
buyers face difficulty filtering listings based on local considerations such as
Ethiopian road conditions, prices in Ethiopian Birr (ETB), fuel type, seating
capacity, and specific geographic availability across cities (e.g., Addis Ababa,
Dire Dawa, Hawassa, Mekelle, Bahir Dar).

The primary objective of this project is to provide an AI-powered semantic
search platform tailored specifically for the Ethiopian car market. Inspired by
improving buyer experience, the application bridges the gap between buyers and
sellers by utilizing Google's Gemini API embedding model (`text-embedding-004`)
and vector cosine similarity algorithms, allowing natural language queries
(e.g., "Diesel SUV in Addis Ababa") to return accurate and contextually
relevant vehicle listings.


3. TECH STACK & ARCHITECTURE
-------------------------------------------------------------------------------
Full-stack Monolithic / Single Page Application (SPA) with Inertia.js bridge.

Backend Components:
- Framework: Laravel 11.x (PHP 8.2+)
- Admin Panel: Laravel Nova 5.x (Custom dashboards, resources, and metric cards)
- Authentication & Auth Framework: Laravel Breeze / Sanctum with Session & API token auth
- Database ORM: Laravel Eloquent ORM (MySQL / SQLite database backends)
- HTTP & Integration Client: Guzzle / Laravel Http Client for external API communication

Frontend Components:
- Framework: Vue 3 (Composition API / Script Setup syntax)
- Inertia.js Bridge: `@inertiajs/vue3` for seamless SPA page rendering without REST boilerplate
- Styling: Tailwind CSS 3.x, `@tailwindcss/forms`, PostCSS, Autoprefixer
- Asset Bundling: Vite 6.x with Vue plugin (`@vitejs/plugin-vue`) and Laravel Vite plugin

AI & Vector Search:
- Model Endpoint: Google Gemini API (`text-embedding-004:embedContent`)
- Vector Comparison: Native PHP mathematical implementation of Cosine Similarity over array embeddings

Architectural Patterns:
- Inertia SPA Architecture: Server-side route handlers rendering Vue components directly with shared state.
- Model-Driven Lifecycle Embeddings: Automatic vector embedding generation on creation and update events.
- Administrative Metrics & Dashboarding: Custom Laravel Nova metric components (`TotalCars`, `CarsByLocation`, `CarsByFuelType`, `AverageCarPrice`, `UsersByRole`, `UsersPerDay`).

5. COMPLEX CHALLENGES & ARCHITECTURAL HIGHLIGHTS
-------------------------------------------------------------------------------
1. Pre-Generated Lifecycle Vector Embeddings
   - Challenge: Generating embeddings on the fly for every search query across the entire database causes significant API overhead and latency.
   - Implementation: Embeddings are calculated and pre-stored in the database whenever a car is created or updated (`updateEmbedding()` method on `Car` model). A composite string combining name, description, make, model, and location (`$this->name.' '.$this->description.' '.$this->make.' '.$this->model.' '.$this->location`) is sent to Gemini's `text-embedding-004` API, and the array payload is saved directly in the JSON/array-cast `embedding` column.

2. Custom Cosine Similarity Vector Calculation in PHP
   - Challenge: Performing vector similarity matches without requiring external vector database infrastructure (like Pinecone or Pgvector).
   - Implementation: Developed a pure PHP `cosineSimilarity($vec1, $vec2)` method in `CarController`. It handles string-to-array decoding, vector padding/truncation (`array_pad`) for magnitude parity, dot product calculation (`array_sum` & `array_map`), vector magnitudes (`sqrt`), and zero-division protection.

3. Hybrid Semantic & Multi-Attribute Search Pipeline
   - Challenge: Combining AI-driven semantic query match scores with strict discrete database filters (e.g. location, fuel type).
   - Implementation: The `search` method generates a vector embedding for the incoming text query via Gemini API, computes cosine similarity scores across all candidate listings, ranks and takes the top 10 relevant items, and then applies secondary case-insensitive string filtering (`mb_strtolower`) for specific attributes like location and fuel type before returning the payload.

4. Integration with Gemini API & Robust Error Handling
   - Challenge: Interfacing with Google's REST `embedContent` endpoint, handling varying API response formats, and resolving development SSL certificate issues.
   - Implementation: Configured HTTP requests using Laravel's `Http::withOptions(['verify' => false])` wrapper for local development, with explicit API key parameters, structured `content.parts` payload format matching Gemini's specifications, and fallback checks for response keys (`$data['embedding']['values']` vs `$data['embeddings'][0]['values']`).

5. Administrative Metrics via Laravel Nova Cards
   - Challenge: Extracting real-time analytical insights for administrators without impacting query performance.
   - Implementation: Built specialized Nova Metric classes (`CarsByLocation`, `CarsByFuelType`, `TotalCars`, `UsersByRole`, `UsersPerDay`) that execute optimized aggregate queries over Eloquent models for Nova dashboard cards.
